# 3-Minute Demo

## Opening

“This is Rollcall, a voice-first emergency accountability system for campuses. It turns a spoken command into a verified, auditable roll call.”

## Demo flow

1. Admin says: “Start roll call for Block B.”
2. Rollcall replies: “Block B has 10 people. Confirm?”
3. Admin says: “Confirm.”
4. Show Telegram sending voice notes with Safe / Need help buttons.
5. One person taps **I’m safe**.
6. Another person taps **I need help**.
7. Show the responder alert and dashboard changing immediately.
8. Admin says: “Claim Aarav.”
9. Admin says: “Mark Aarav resolved.”
10. Show an unanswered person escalating to `UNACCOUNTED`.
11. Admin says: “What is the status of Block B?”
12. Show the event timeline.

## Closing

“The AI proposes an action, n8n validates it, Supabase records it, and the dashboard proves what happened.”
